shape

A Markdown file that starts with YAML front matter between two --- lines. Only key: value lines and one level of indented blocks are read; there are no lists or anchors. After the front matter comes free Markdown about your agent, and optionally one fenced block named rules.

---
name: Rook
color: "#4fd1c5"
crystal: aquamarine
author: you
style:
  learns: 0.45      # how fast memory moves (0..1)
  observes: 0.35    # how often a shown tell is caught (0..1)
  probes: 0.20      # exploration: trying moves that are not yet best (0..1)
reaction:
  observe: 0.30     # seconds to see a tell
  respond: 0.20     # seconds to answer it
  sub_id: 0.10      # reflex: emergency dodge when only this fits
gradient:
  threshold: 3      # 1x at 0.5, 2x at 2, {{trigger::hide}} at this value (2..5)
  decay_s: 3        # calm fades the gradient (e-fold seconds)
  bad_outcome: 0.2  # extra gradient for a wrong read (0..1)
hide: best          # best | block | dodge
attack:
  feint: 0.35       # share of feints when attacking
  conceal: 0.30     # chance your tell is hidden
  bluff: 0.10       # chance a shown tell lies
notes: "patient, counters feints, hides early"
---

the optional rules block

One fenced block whose info string is rules, holding plain key: value settings. Only these three keys exist:

openpunch · feint · anyyour first attack
counter_bias0..1leans your answers toward COUNTER (adds 4 × bias to its memory score)
after_hithide · counter · nonewhat you do on the exchange after a hit lands on you

safety

  • Nothing in an agent.md is ever executed: no eval, no script, no HTML. Every value is shown with textContent.
  • Files over 16 KB are refused; unknown keys, lists and deeper nesting are ignored with a warning; __proto__, constructor and prototype keys are refused; numbers are clamped to their range.
  • A code block other than rules is shown as text, and the page tells you it was not run.
  • Share links carry the file in the URL #fragment, which is never sent to any server. Results are plain JSON, and importing one replays it and verifies it rather than trusting it.

how a bout runs

24 exchanges with the attacker alternating. Damage taken: PUNCH vs DODGE 0 · vs BLOCK 3 · vs COUNTER 10; FEINT vs DODGE 4 (off balance) · vs BLOCK 0 · vs COUNTER: the attacker takes 8. Points = damage dealt. Seeded (mulberry32), so a bout with the same seed and the same starting crystals replays identically, which is what makes result files verifiable.
